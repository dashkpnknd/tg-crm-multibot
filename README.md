# Telegram CRM Multibot

Telegram CRM для работы с аккаунтами, чатами, отправкой сообщений и Stories. Рабочая точка входа — `CRM.py`; обработчики находятся в `plugins/`.

## Запуск

1. Создайте виртуальное окружение и установите зависимости: `pip install -r requirements.txt`.
2. Задайте в окружении переменные из `.env.example`: токен бота, два Telegram API hash и ID журнала.
3. Запустите `python CRM.py`.

`runtime_config.py` читает значения только из окружения. Сессии, аккаунты, базы, журналы и рабочие файлы хранятся вне Git. Код импорта проверен с зависимостями из `requirements.txt`; подключение к Telegram требует действующих учётных данных.

## Связи и границы проекта

Это отдельная реализация Telegram CRM с модулями аккаунтов, чатов, сообщений и Stories. `tg-dialog-hub` решает близкую задачу другим кодом; общую базу или взаимозаменяемость этих проектов предполагать нельзя.
